# 実装仕様書: ログイン機能（Laravel Sanctum Cookie認証）

## 目的

Laravel Sanctum Cookie認証を使用したAPI認証システムを構築し、メールアドレスとパスワードによる安全なログイン/ログアウト機能を提供する。

## 要件

- [ ] Laravel Sanctum Cookie認証によるAPI認証
- [ ] メールアドレス + パスワードでのログイン機能
- [ ] ログアウト機能
- [ ] 現在認証済みユーザー情報取得API（GET /api/user）
- [ ] CSRF保護（Sanctum標準機能）
- [ ] セッション再生成（セッションフィクス化攻撃対策）
- [ ] PHPUnit テストコード（Unit/Feature）
- [ ] API仕様書・セットアップガイド

## 技術仕様

- 言語: PHP 8.4
- フレームワーク: Laravel 12.x
- 認証: Laravel Sanctum（Cookie認証）
- テスト: PHPUnit 11
- アーキテクチャ: Laravel 7層レイヤードアーキテクチャ
- 依存関係: laravel/sanctum

## 実装手順（Phase単位で記載）

### Phase 0: 環境準備

- Laravel Sanctumパッケージインストール
- Sanctum設定ファイル発行
- データベースマイグレーション実行
- CORS設定（config/cors.php）
- セッション設定（config/session.php）

### Phase 1: Model層

- User Model（すでに存在する場合は確認のみ）
  - fillable: name, email, password
  - hidden: password, remember_token
  - casts: email_verified_at, password
- UserFactory（テスト用）

### Phase 2: Repository層

- UserRepositoryInterface（契約）
  - findByEmail(string $email): ?User
- UserRepository（実装）
  - Eloquent経由でUserを検索

### Phase 3: UseCase層

- LoginData（Laravel Data DTO）
  - email: string
  - password: string
- AuthenticatedUserData（Laravel Data DTO）
  - id: int
  - name: string
  - email: string
- LoginUseCase
  - メール・パスワード検証
  - Laravel標準のAuth::attempt()使用
  - ログイン成功時にセッションを再生成（session()->regenerate()）
- LogoutUseCase
  - Auth::logout()
  - セッション無効化（session()->invalidate()）
  - CSRFトークン再生成（session()->regenerateToken()）
- GetAuthenticatedUserUseCase
  - 現在認証済みユーザーをAuthenticatedUserDataで返す

### Phase 4: Controller層

- LoginRequest（FormRequest）
  - email: required|email
  - password: required|string
- AuthController（API）
  - POST /api/login → LoginUseCase実行、成功時はユーザー情報を返す
  - POST /api/logout → LogoutUseCase実行
  - GET /api/user → GetAuthenticatedUserUseCase実行、認証済みユーザー情報を返す
- APIルート定義（routes/api.php）
- レート制限設定（Laravel標準のThrottleMiddleware使用）

### Phase 5: セキュリティ強化

- SecurityHeadersMiddleware（必要に応じて）
  - X-Frame-Options: DENY
  - X-Content-Type-Options: nosniff
  - Referrer-Policy: no-referrer
- パスワードポリシー設定（config/hashing.php）
  - Argon2id推奨
- セッション設定強化（config/session.php）
  - secure: true（本番環境）
  - http_only: true
  - same_site: 'lax'
- CORS設定（config/cors.php）
  - supports_credentials: true
  - allowed_origins: SPAのドメイン

### Phase 6: サービスプロバイダー登録

- UserRepositoryInterfaceをUserRepositoryにバインド（app/Providers/AppServiceProvider.php）

### Phase 7: ドキュメント作成

- API仕様書（.claude/specs/api-spec-auth.md）
  - エンドポイント一覧
  - リクエスト/レスポンス例
- セットアップガイド（.claude/specs/setup-guide-auth.md）
  - Sanctum初期設定手順
  - 環境変数設定
  - マイグレーション実行手順

### Quality Checks

- PHPStan静的解析通過
- Laravel Pintコーディング規約チェック通過
- PHPUnitテスト実行成功（全テストパス）
- Deptrac依存関係チェック通過

**重要**: 実装手順はPhase単位で細かく分割してください。
各PhaseごとにRED → GREEN → REFACTORサイクルを実行します。
