# 実装仕様書: ダッシュボード画面

## 目的
ログイン後に遷移するダッシュボード画面をReact/TypeScriptで実装する。モック画面（memos/screens/dashboard/screen.png）に基づき、認証済みユーザー向けのメインページを構築する。

## 要件
- [ ] 認証済みユーザー専用のAuthenticatedLayoutを作成
- [ ] サイドナビゲーション（ホーム、ダッシュボード、レポート、設定、ヘルプ＆サポート）
- [ ] トップナビバー（検索、通知、ユーザー情報、ログアウトボタン）
- [ ] ウェルカムバナー（ユーザー名表示、日付、新規作成ボタン）
- [ ] 統計カード3枚（アクティビティ、未完了タスク、通知）
- [ ] 最近の推移チャートセクション（プレースホルダー）
- [ ] 最近のアクティビティリスト
- [ ] レスポンシブ対応（モバイル: サイドナビ非表示、ハンバーガーメニュー）
- [ ] ダークモード対応

## 技術仕様
- 言語: TypeScript (React)
- フレームワーク: Inertia.js + React
- スタイリング: Tailwind CSS v4
- テスト: Vitest + React Testing Library
- データ取得: Inertia Props（サーバーサイドからprops経由）

## 画面構成

### レイアウト: AuthenticatedLayout
- サイドナビバー（左固定、md以上で表示）
- トップナビバー（上部固定）
- メインコンテンツエリア（スクロール可能）

### ページ: Dashboard
- ウェルカムセクション（ユーザー名、日付、新規作成ボタン）
- 統計カード x 3（グリッドレイアウト）
- チャート + アクティビティ（2カラムレイアウト）

## Inertia Props型定義

```typescript
interface DashboardProps {
  stats: {
    activity: { value: string; change: string; changeDirection: 'up' | 'down' };
    incompleteTasks: { count: number; overdueCount: number };
    notifications: { count: number };
  };
  recentActivities: Array<{
    id: number;
    title: string;
    description: string;
    timeAgo: string;
    type: 'info' | 'success' | 'warning' | 'default';
  }>;
  chartData: {
    total: number;
    changePercent: string;
    labels: string[];
  };
}
```
