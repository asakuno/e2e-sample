# 実装仕様書

## 目的
既存のLaravelアプリケーションにユーザー新規登録機能を追加する。name, email, password, password_confirm の4フィールドによる登録フォーム処理をバックエンドで実装する。

## 要件
- [ ] ユーザー新規登録エンドポイント（POST）の実装
- [ ] name, email, password, password_confirmation のバリデーション
- [ ] パスワードはHash::make()でハッシュ化して保存
- [ ] 登録成功後、自動ログイン＋セッション再生成
- [ ] 登録成功後、ダッシュボードへリダイレクト（Inertia）
- [ ] メールアドレスの一意性チェック
- [ ] パスワードポリシー適用（最小8文字、大小英数記号）
- [ ] レート制限の適用
- [ ] 7層アーキテクチャに準拠した実装

## 技術仕様
- 言語: PHP 8.4+
- フレームワーク: Laravel 12.x, Inertia.js
- アーキテクチャ: 7層レイヤードアーキテクチャ
- 依存関係: spatie/laravel-data（DTO）

## 実装手順（Phase単位で記載）

### Phase 0: 環境準備
- 既存のUser Modelの確認・拡張（必要に応じて）

### Phase 1: 計画・レビュー
- 7層アーキテクチャ設計
- UseCase/DTO/Repository設計

### Phase 2: DTO層
- RegisterUserData（Laravel Data DTO）

### Phase 3: Repository層
- UserRepositoryInterfaceの拡張（createメソッド追加）
- UserRepositoryの拡張

### Phase 4: UseCase層
- RegisterUserUseCase（ユーザー作成、ハッシュ化、自動ログイン、セッション再生成）

### Phase 5: Request・Controller層
- RegisterRequest（FormRequest - バリデーション）
- RegisterPageController（Web Controller - Inertia）
- ルート定義

### Phase 6: DI設定・セキュリティ
- ServiceProvider登録（必要に応じて）
- レート制限設定
