# 実装仕様書: ログイン画面（Frontend - Inertia.js）

## 目的

既存のバックエンドAPI（Laravel Sanctum Cookie認証）に対応するログイン画面をReact/TypeScript + Inertia.jsで構築する。

## 要件

- [ ] ログインフォーム（メールアドレス + パスワード）の表示
- [ ] Inertia `useForm` + `withPrecognition()` によるフォーム送信・バリデーション
- [ ] パスワード表示/非表示トグル
- [ ] バリデーションエラーの表示（リアルタイム + サーバーサイド）
- [ ] ログイン成功時のリダイレクト
- [ ] 「パスワードをお忘れですか？」「新規登録はこちら」リンク
- [ ] レスポンシブデザイン（モバイル対応）
- [ ] Vitest/RTL テストコード
- [ ] アクセシビリティ対応（ラベル、フォーカス管理）

## 技術仕様

- 言語: TypeScript
- フレームワーク: React 19 + Inertia.js v2.3+
- スタイリング: Tailwind CSS v4
- フォーム: `@inertiajs/react` の `useForm` + `withPrecognition()`
- テスト: Vitest + React Testing Library
- デザイン参考: `/memos/screens/auth/login/`

## UI仕様

デザインモック（`/memos/screens/auth/login/japanese_login_screen.png`）に基づく:

- 背景: グレー（`#EEF2F6`）
- カード: 白背景、角丸、シャドウ、最大幅400px
- ヘッダー: 「ログイン」テキスト（太字、中央揃え）
- フォームフィールド:
  - メールアドレス: `type="email"`, placeholder `example@email.com`
  - パスワード: `type="password"`, 目アイコンで表示切替
- ボタン: 青色（`#2767cf`）、「ログインする」
- フッターリンク: 「パスワードをお忘れですか？」「新規登録はこちら」

## バックエンド連携

既存のAPI Controller（`App\Http\Controllers\Api\AuthController`）と連携:
- ログイン: `POST /api/login`（email, password）
- ただしInertia.jsの場合は `POST /login`（Web Controller経由）を使用する可能性あり

**注意**: Web Controller（`AuthPageController`）の新規作成が必要になる可能性がある。

## 実装手順（Phase単位で記載）

### Phase 1: 計画・設計
- UI/UXレビュー
- コンポーネント設計
- ルーティング設計（Web Controller + Inertia）
- DESIGN.md作成

### Phase 2: バックエンド補完（Web Controller）
- `AuthPageController`（Inertia用Web Controller）
  - `GET /login` → ログインページ表示
  - `POST /login` → LoginUseCase実行 → リダイレクト
- Web用ルート定義（`routes/web.php`）
- Web用LoginRequest（必要に応じて既存を流用）

### Phase 3: 基本UIコンポーネント
- GuestLayout（未認証用レイアウト）
- InputField コンポーネント（ラベル + 入力 + エラー表示）
- PasswordInput コンポーネント（表示/非表示トグル付き）
- PrimaryButton コンポーネント

### Phase 4: ログインページ
- Login ページコンポーネント（`resources/js/pages/Auth/Login.tsx`）
- Inertia `useForm` + `withPrecognition()` によるフォーム処理
- バリデーションエラー表示
- リダイレクト処理

### Quality Checks
- TypeScript型チェック通過
- Biome lint/formatチェック通過
- Vitest テスト実行成功
- Vite ビルド確認

**重要**: 実装手順はPhase単位で細かく分割してください。
各PhaseごとにRED → GREEN → REFACTORサイクルを実行します。
