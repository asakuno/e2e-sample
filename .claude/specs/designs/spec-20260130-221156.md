# 実装仕様書: CI/CD パイプライン（Backend + Frontend テスト）

## 目的

GitHub Actions を使用して、バックエンド（PHPUnit/PHPStan/Pint/Deptrac）とフロントエンド（Vitest/Biome/TypeCheck/Build）の品質チェックをPR・pushイベントで自動実行するCIパイプラインを構築する。

## 要件

- [ ] PR作成・更新時にバックエンドの品質チェック（PHPStan, Pint, PHPUnit, Deptrac）を自動実行
- [ ] PR作成・更新時にフロントエンドの品質チェック（TypeCheck, Biome, Vitest, Build）を自動実行
- [ ] Backend と Frontend のジョブを並列実行してCI時間を短縮
- [ ] PHP 8.4 + Node.js 環境をセットアップ
- [ ] SQLite in-memory でテスト用DB構築（phpunit.xml準拠）
- [ ] Composer / Yarn キャッシュでインストール高速化
- [ ] main ブランチへの push でも CI を実行

## 技術仕様

- プラットフォーム: GitHub Actions
- PHP: 8.4
- Node.js: 22.x（LTS）
- パッケージマネージャ: Composer (Backend), Yarn (Frontend)
- DB: SQLite in-memory（テスト用）
- キャッシュ: actions/cache（Composer, Yarn）

## 実装手順（機能単位で記載）

### Phase 1: Backend CI ワークフロー
- `.github/workflows/ci.yml` に backend ジョブを作成
- PHP 8.4 セットアップ（shivammathur/setup-php）
- Composer キャッシュ & install
- `.env.testing` セットアップ（APP_KEY生成、SQLite設定）
- PHPStan 静的解析
- Laravel Pint コーディング規約チェック（`--test`）
- PHPUnit テスト実行
- Deptrac 依存関係チェック

### Phase 2: Frontend CI ワークフロー
- 同一 `.github/workflows/ci.yml` に frontend ジョブを作成
- Node.js 22.x セットアップ
- Yarn キャッシュ & install
- TypeScript 型チェック（`yarn typecheck`）
- Biome lint/format チェック（`yarn check`）
- Vitest テスト実行（`yarn test`）
- Vite ビルド確認（`yarn build:all`）

## 完了条件

- [ ] `ci.yml` が `.github/workflows/` に配置されている
- [ ] PR作成時にBackend/Frontendジョブが並列実行される
- [ ] 全チェック項目がジョブステップとして定義されている
- [ ] キャッシュが適切に設定されている
- [ ] mainブランチpush時にもCIが実行される
