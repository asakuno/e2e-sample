# 画面種別ごとの設計パターン集

よくある画面種別ごとに、設計のレシピ（構成要素、情報の優先順位、レイアウト方針）をまとめる。

---

## 一覧画面（List / Index）

**目的**: 複数のアイテムを俯瞰し、目的のアイテムを見つける・操作する

### 構成要素

| 要素             | 優先度 | 備考                             |
| ---------------- | ------ | -------------------------------- |
| ページタイトル   | P1     | 何の一覧か                       |
| 検索/フィルタ    | P1     | データ量が多い場合は必須         |
| アイテム一覧     | P1     | メインコンテンツ                 |
| 新規作成ボタン   | P1     | 主要アクション                   |
| ページネーション | P2     | 件数が多い場合                   |
| 一括操作         | P2     | 管理画面で必要な場合             |
| 表示件数切替     | P3     | 通常はデフォルトで十分           |
| カラム表示設定   | P3     | パワーユーザー向け               |

### レイアウト方針

- **〜5属性、比較重要**: テーブル
- **ビジュアル重要、〜30件**: カード
- **シンプル、時系列**: リスト

### 設計チェックリスト

- [ ] 空の状態（0件）の表示を考えたか
- [ ] 検索結果0件の表示を考えたか
- [ ] ローディング状態を考えたか
- [ ] 1件、10件、100件、1000件での見え方を考えたか
- [ ] 長いテキストの切り詰めルールを決めたか

## 詳細画面（Detail / Show）

**目的**: 1つのアイテムの全情報を確認し、操作する

### 構成要素

| 要素             | 優先度 | 備考                             |
| ---------------- | ------ | -------------------------------- |
| アイテム識別情報 | P1     | タイトル、ID、ステータス         |
| 主要情報         | P1     | このアイテムの核心的な情報       |
| アクションボタン | P1     | 編集、削除等の主要操作           |
| 補足情報         | P2     | 関連データ、メタデータ           |
| 関連アイテム     | P2     | リレーション先のデータ           |
| 履歴/ログ        | P3     | 変更履歴、コメント               |
| メタデータ       | P3     | 作成日、更新日、作成者           |

### レイアウト方針

```
┌─────────────────────────────────────┐
│ ← 戻る          [編集] [削除]       │  ヘッダー: 識別情報 + アクション
├─────────────────────────────────────┤
│ タイトル（大）                       │
│ ステータスバッジ                     │  P1: 核心情報
│                                     │
│ 主要情報セクション                   │
├─────────────────────────────────────┤
│ 補足情報          │ 関連アイテム     │  P2: 2カラム or タブ
├─────────────────────────────────────┤
│ 履歴/ログ（折りたたみ可）            │  P3: 折りたたみ
└─────────────────────────────────────┘
```

### 設計チェックリスト

- [ ] 一覧画面への戻り導線があるか
- [ ] 編集/削除のアクションが分かりやすいか
- [ ] P3情報は折りたたまれているか
- [ ] 関連アイテムへの遷移導線があるか

## ダッシュボード

**目的**: 全体の状況を素早く把握し、異常や傾向を発見する

### 構成要素

| 要素             | 優先度 | 備考                             |
| ---------------- | ------ | -------------------------------- |
| KPI サマリー     | P1     | 最重要指標を大きな数字で         |
| トレンドグラフ   | P1     | 時系列の傾向                     |
| アラート/通知    | P1     | 異常値、要対応項目               |
| 詳細テーブル     | P2     | ドリルダウン用                   |
| フィルタ/期間選択| P2     | 分析軸の切替                     |
| 二次的グラフ     | P3     | 補足的な分析                     |

### レイアウト方針

```
┌──────────┬──────────┬──────────┬──────────┐
│  KPI 1   │  KPI 2   │  KPI 3   │  KPI 4   │  カード: 主要KPI
├──────────┴──────────┴──────────┴──────────┤
│                                            │
│          メイントレンドグラフ                │  グラフ: 時系列
│                                            │
├────────────────────────┬───────────────────┤
│     サブグラフ1        │   サブグラフ2      │  グラフ: 補足
├────────────────────────┴───────────────────┤
│          詳細テーブル（最新N件）             │  テーブル: ドリルダウン
└────────────────────────────────────────────┘
```

### 設計チェックリスト

- [ ] 最も重要なKPIが最も目立っているか
- [ ] 数字は加工されているか（1234567 → 1.23M）
- [ ] 前期比/前年比等の比較基準があるか
- [ ] 異常値が視覚的にハイライトされるか
- [ ] データの鮮度（最終更新時刻）が表示されているか
- [ ] ドリルダウンの導線があるか

## 設定画面（Settings）

**目的**: アプリケーションの動作をカスタマイズする

### 構成要素

| 要素             | 優先度 | 備考                             |
| ---------------- | ------ | -------------------------------- |
| カテゴリ分類     | P1     | 設定項目のグループ化             |
| 設定項目         | P1     | ラベル + 現在の値 + 操作UI       |
| 説明テキスト     | P2     | 各設定の意味（簡潔に）           |
| 保存/リセット    | P2     | 変更の確定                       |
| 詳細設定         | P3     | 上級者向け（折りたたみ）         |

### レイアウト方針

- **項目が少ない（〜10）**: 1カラムのリスト形式
- **項目が多い（10〜）**: 左カテゴリ + 右設定項目（マスター/詳細）
- **モバイル**: カテゴリ一覧 → カテゴリ内設定（画面遷移）

```
┌──────────────┬──────────────────────────────┐
│ カテゴリ     │                              │
│              │  カテゴリタイトル             │
│ ● 一般       │                              │
│   通知       │  設定項目1                    │
│   セキュリティ│  [説明テキスト]              │
│   連携       │  [トグル / セレクト / 入力]   │
│   詳細       │                              │
│              │  設定項目2                    │
│              │  ...                         │
│              │                              │
│              │          [保存] [リセット]    │
└──────────────┴──────────────────────────────┘
```

### 設計チェックリスト

- [ ] 変更が即時反映か保存ボタン必要かが明確か
- [ ] 危険な設定（データ削除、アカウント無効化）に警告があるか
- [ ] デフォルト値にリセットできるか
- [ ] 説明テキストは最小限か（過剰な説明はノイズ）

## フォーム画面（Create / Edit）

**目的**: データを入力・編集して保存する

### 構成要素

| 要素             | 優先度 | 備考                             |
| ---------------- | ------ | -------------------------------- |
| フォームタイトル | P1     | 何を作成/編集しているか          |
| 必須フィールド   | P1     | 最低限必要な入力項目             |
| 送信ボタン       | P1     | 主要アクション                   |
| 任意フィールド   | P2     | あると便利な入力項目             |
| バリデーション   | P2     | エラー表示、ヒント               |
| キャンセル導線   | P2     | 入力を破棄して戻る               |
| 下書き保存       | P3     | 長いフォームで有効               |
| 入力プレビュー   | P3     | 入力結果の確認                   |

### レイアウト方針

- **項目が少ない（〜5）**: 1カラム、中央配置
- **項目が多い（5〜15）**: セクション分け、1カラム
- **項目が非常に多い（15〜）**: ステップフォーム（ウィザード）
- **幅**: 最大幅600-700pxが読みやすい

### 設計チェックリスト

- [ ] 必須/任意が明確に区別されているか
- [ ] エラーメッセージがフィールドの近くに表示されるか
- [ ] Tab キーで論理的な順序で移動できるか
- [ ] 長いフォームにプログレス表示があるか
- [ ] 入力途中で画面を離れる時の確認があるか
- [ ] 送信後のフィードバック（成功/失敗）が明確か

---

## 検索結果画面

**目的**: 検索クエリに対する結果を表示し、目的のアイテムを見つける

### 構成要素

| 要素             | 優先度 | 備考                             |
| ---------------- | ------ | -------------------------------- |
| 検索ボックス     | P1     | クエリの表示・再編集             |
| 結果件数         | P1     | 何件見つかったか                 |
| 検索結果リスト   | P1     | メインコンテンツ                 |
| フィルタ/絞込み  | P2     | カテゴリ、日付、属性で絞込み     |
| ソート           | P2     | 関連度順、日付順、名前順         |
| ページネーション | P2     | 結果が多い場合                   |
| 検索サジェスト   | P3     | 「もしかして」機能               |

### レイアウト方針

```
┌────────────────────────────────────────────┐
│  🔍 [検索クエリ                    ] [検索] │
├────────────────────────────────────────────┤
│  "キーワード" の検索結果: 142件             │
│  関連度順 ▼  │  フィルタ: [カテゴリ ▼]     │
├──────────────┼─────────────────────────────┤
│ フィルタ     │ 結果1                        │
│              │   タイトル（キーワードハイライト）│
│ □ カテゴリA  │   スニペット...               │
│ □ カテゴリB  │   メタ情報                    │
│ □ カテゴリC  │                              │
│              │ 結果2                        │
│ 日付範囲     │   ...                        │
│ [開始]-[終了]│                              │
└──────────────┴─────────────────────────────┘
```

### 設計チェックリスト

- [ ] 検索キーワードが結果内でハイライトされるか
- [ ] 結果0件の表示と次のアクション提案があるか
- [ ] 検索クエリが結果画面でも編集可能か
- [ ] フィルタ適用後の件数がリアルタイムで更新されるか
- [ ] 各結果アイテムのクリック可能範囲が十分か
