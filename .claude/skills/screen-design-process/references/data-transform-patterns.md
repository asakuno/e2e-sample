# データ変換パターン集

生データをユーザーが理解しやすい形に変換する、頻出10パターン。

**加工の判断基準**: 「このデータを見て、ユーザーは0.5秒以内に意味を理解できるか？」

---

## 1. 日付 → 相対時間
```
2024-03-17T14:23:00Z → 「2日前」「3時間前」「たった今」
```
閾値: 1時間以内 → 分、24時間以内 → 時間、7日以内 → 日、それ以降 → 日付

## 2. 生年月日 → 年齢
```
1990-05-15 → 「34歳」
```

## 3. 数値 → プログレス表示
```
75 (%) → [████████░░] 75%
```
タスク完了率、アップロード進捗、目標達成率に有効

## 4. ステータスコード → ラベル+色
```
PENDING → 🟡 保留中
APPROVED → 🟢 承認済み
REJECTED → 🔴 却下
```

## 5. 数値 → 評価の視覚化
```
4.2 → ★★★★☆ (4.2)
```

## 6. Boolean → アイコン
```
true → ✓   false → −
```
一覧画面で省スペース。「はい/いいえ」より高速に認識可能

## 7. 金額 → フォーマット+通貨
```
150000 → ¥150,000
```
桁区切り必須。小数点以下は文脈に応じて

## 8. ユーザー → アバター+名前
```
{name: "田中太郎", avatar: null} → 田（アバター）+ 田中太郎
```
イニシャルアバターで視認性向上

## 9. 長文 → 切り詰め+展開
```
"これは非常に長い説明文で..." → "これは非常に長い説明文で…" [もっと見る]
```
一覧画面では2-3行で切り詰め

## 10. カウント → バッジ表示
```
3 (未読) → 未読メッセージ [3]
0 (未読) → （非表示）
```
0件の時は非表示にして視覚ノイズを減らす
