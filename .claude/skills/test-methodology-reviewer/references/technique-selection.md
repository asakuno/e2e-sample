## 技法の分類とレベル別適用度

| 技法 | 分類 | Unit | Integration | E2E |
|------|------|:----:|:-----------:|:---:|
| **同値分割** | ブラックボックス | ◎ | ○ | △ |
| **境界値分析** | ブラックボックス | ◎ | ○ | △ |
| **デシジョンテーブル** | ブラックボックス | ◎ | ◎ | ○ |
| **状態遷移テスト** | ブラックボックス | ○ | ◎ | ◎ |
| **ユースケーステスト** | ブラックボックス | △ | ○ | ◎ |
| **ステートメントカバレッジ** | ホワイトボックス | ◎ | ○ | - |
| **ブランチカバレッジ** | ホワイトボックス | ◎ | ○ | - |
| **条件カバレッジ** | ホワイトボックス | ○ | △ | - |
| **エラー推測** | 経験ベース | ◎ | ◎ | ◎ |
| **探索的テスト** | 経験ベース | △ | ○ | ◎ |

**凡例**: ◎ 最適 / ○ 適用可 / △ 限定的 / - 不適

## 技法選択のガイドライン

```
┌─────────────────────────────────────────────────────┐
│ テスト対象の特性から技法を選択                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  入力値に範囲がある？                                │
│    ├─ Yes → 境界値分析 + 同値分割                   │
│    └─ No                                           │
│                                                     │
│  複数条件の組み合わせがある？                         │
│    ├─ Yes → デシジョンテーブル                      │
│    └─ No                                           │
│                                                     │
│  状態遷移がある？                                    │
│    ├─ Yes → 状態遷移テスト                         │
│    └─ No                                           │
│                                                     │
│  ユーザーシナリオが重要？                            │
│    ├─ Yes → ユースケーステスト                      │
│    └─ No → ステートメント/ブランチカバレッジ         │
│                                                     │
└─────────────────────────────────────────────────────┘
```
