│ プラン: premium                              │
│ 累計購入額: 150000                           │
│ ポイント残高: 3200                           │
│ 紹介コード: ABC123                           │

```

│     📞 090-1234-5678                        │
│                                             │
├─────────────────────┬───────────────────────┤
│ プラン               │ 累計購入額            │
│ Premium ⭐           │ ¥150,000             │  ← P1: KPI的な情報
│                      │                      │
│ ポイント残高          │ 最終購入              │
│ 3,200 pt             │ 1週間前              │  ← P2: 補足情報
├──────────────────────┴──────────────────────┤
│ ▶ 詳細情報                                  │  ← P3: 折りたたみ
│   34歳 / 東京都渋谷区 / 登録: 2023年1月     │
│                                             │
│ ▶ 管理メモ                                  │  ← P3: 折りたたみ
│   タグ: VIP, 法人 / メモ: 要フォロー        │
└─────────────────────────────────────────────┘
```

改善点:
- P1（名前・連絡先・ステータス）が最も目立つ
- P2（プラン・金額・ポイント）がカード形式で一覧性を確保
- P3（住所・登録日・管理メモ）は折りたたみ
- 生データを加工（日付→相対時間、金額→桁区切り、ステータス→色付きバッジ）

## DB直結テーブル → ユーザー視点テーブル

### Before（NG: SELECT * の結果）

```
┌────┬──────────┬──────────────────────┬──────────────┬───────┬──────────┬────────┐
│ id │ name     │ email                │ created_at   │ status│ birth_dt │ dept_id│
├────┼──────────┼──────────────────────┼──────────────┼───────┼──────────┼────────┤
│ 1  │ 田中太郎 │ tanaka@example.com   │ 2023-01-15T..│ 1     │ 1990-05..│ 3      │
│ 2  │ 鈴木花子 │ suzuki@example.com   │ 2023-02-20T..│ 1     │ 1985-08..│ 1      │
│ 3  │ 佐藤次郎 │ sato@example.com     │ 2022-11-05T..│ 0     │ 1992-12..│ 3      │
└────┴──────────┴──────────────────────┴──────────────┴───────┴──────────┴────────┘
```

問題: DB カラム名がそのまま、ステータスが数値、日付が生データ、不要なIDが表示

### After（OK: ユーザーが必要な情報を加工して表示）

```
┌──────────────────────────────────────────────────────────────┐
│ □  名前           部署      年齢   登録日     ステータス     │
├──────────────────────────────────────────────────────────────┤
│ □  田 田中太郎    開発部     34歳   1年前     🟢 有効       │
│ □  鈴 鈴木花子    営業部     39歳   1年前     🟢 有効       │
│ □  佐 佐藤次郎    開発部     31歳   1年4ヶ月前 ⚫ 無効       │
└──────────────────────────────────────────────────────────────┘
```

改善点:
- id を非表示（ユーザーには不要）、dept_id を部署名に変換
- birth_date を年齢に、created_at を相対時間に、status を色付きラベルに
- アバターで視認性向上、チェックボックスで一括操作対応

## ラベル過剰 → 最小限のヒント

### Before（NG: 全てにラベル）

```
┌─────────────────────────────────┐
│ 名前:     田中太郎              │
│ メール:   tanaka@example.com    │
│ 電話番号: 090-1234-5678         │
│ 住所:     東京都渋谷区...       │
│ 会員番号: 00123                 │
│ 登録日:   2023年1月15日         │
│ ステータス: アクティブ          │
└─────────────────────────────────┘
```

### After（OK: フォーマットで自明なものはラベル不要）

```
┌─────────────────────────────────┐
│                                 │
│  田中太郎            🟢 有効   │  ← 名前は自明、ステータスはバッジ
│                                 │
│  tanaka@example.com             │  ← メールはフォーマットで自明
│  📞 090-1234-5678              │  ← アイコンで種別を表現
│  📍 東京都渋谷区...            │  ← アイコンで種別を表現
│                                 │
│  会員No. 00123 · 登録 1年前    │  ← 不明なものだけ最小限のラベル
│                                 │
└─────────────────────────────────┘
```

改善点:
- 名前・メール・電話はフォーマットで自明なのでラベル削除
- 電話と住所はアイコンで種別を表現
- 会員番号は何の番号か不明なので「会員No.」を補完
- 登録日は相対時間に加工
